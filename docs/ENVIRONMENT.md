- Python 3.11.15
- PyTorch 2.11.0+cu128
- torchvision 0.26.0+cu128
- CUDA 12.8
- cuDNN 91900
- GPU: NVIDIA RTX A6000
- timm 1.0.28
- pandas 2.3.3
- scikit-learn 1.9.0
- scipy 1.17.1
- matplotlib 3.11.0
- seaborn 0.13.2
